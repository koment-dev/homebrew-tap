# koment-dev/homebrew-tap

Homebrew formulae for [koment](https://github.com/koment-dev/koment) — checked
out-of-band rationale for code.

```sh
brew install koment-dev/tap/koment
```

`Formula/koment.rb` is the formula attached to each koment release. It is
copied here rather than generated here, so the version it names is the one
that release published.
